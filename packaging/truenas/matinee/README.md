# Matinee

[Matinee](https://matinee.yeix.io) is a media server for your movies, TV shows and music, with a web player and apps for phones and TVs.

Add your media folders under Additional Storage (read-only is fine), then pick them when you add a library in Matinee.
See the [guide](https://matinee.yeix.io/docs/) for configuration options.
