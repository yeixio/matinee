Matinee 0.2.9 makes PC games feel like a game console, and fixes TV navigation.

### New

- **One Steam button**: PC games is now a single **Steam** button. It opens Steam's Big Picture, its TV and controller screen, where you browse, start, install and remove games, like on a handheld gaming PC. See [Games](https://matinee.yeix.io/docs/server/games/).
- **TV mode for a Steam-only computer**: set `MATINEE_GAMEHOST_TV_MODE=true` on a game host that only runs Steam, such as a Steam container, and Steam stays in Big Picture when a player leaves.
- **Typing and a mouse on a TV**: while a PC game plays, press **Back** on the TV remote (or the keypad button on a phone or tablet) to type text or a password with the TV's keyboard, press Enter, Tab or Backspace, or use the controller as a mouse. Handy for signing in to Steam.

### Fixed

- Moving a large library's database between SQLite and PostgreSQL no longer fails partway with `items_parent_id_fkey`.

### Apps

Version 1.0.44 of the phone and TV apps:

- On a TV, up and down now go to the nearest item in the next row, even when it isn't lined up with the one you're on.
- Back on a TV now goes straight to the previous screen, no matter how far down you are, and from the top bar it leaves Matinee.
- The TV's Filter & sort fits on one screen.
- On phones and tablets, the on-screen arrows in PC games push firmly, so Steam's menus and games react to a light touch.
- Typing and the controller-as-mouse menu for PC games on TVs, phones and tablets.

### Updating

Packages, the Docker image, the Helm chart, the Mac app and the Windows app update as usual. See [Updating](https://matinee.yeix.io/docs/getting-started/updating/) in the guide.
