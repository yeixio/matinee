Matinee 0.2.7 brings arcade games and more emulators, games on every install including Mac and Windows, Steam on the TV apps, and a built-in way to move your database.

### New

- **Arcade games**: put MAME sets in a Games library, in a folder such as `mame` or `arcade`, and Matinee plays them with its arcade emulator. More consoles play too, and games get summaries and genres from Wikipedia. See [Arcade games](https://matinee.yeix.io/docs/server/arcade/).
- **Games on every install**: the emulators now come with the Docker image, the apt and dnf packages, the Mac app and the Windows app, so games play with nothing to set up.
- **Games from 7z and zip sets**: a console game packed with many versions of itself now plays the best one: a good dump, from your region first.
- **Add an emulator from the game**: when Matinee has no emulator for a game, admins can add one right from the game's page.
- **Which game files were left out**: admins see which files in a Games library weren't added, and why.
- **PC games in the Games library**: Steam and your installed PC games now sit at the top of each Games library for admins. If the game host isn't answering, it says why.
- **Keyboard and mouse for PC games**: in the web app, your keyboard and mouse control PC games and Steam, so you can click, type and play without a controller. **Capture mouse** is for games that turn the view with the mouse. See [PC games from Steam](https://matinee.yeix.io/docs/server/games/#pc-games-from-steam-preview).
- **Move your database**: move from SQLite to PostgreSQL, from one PostgreSQL server to another, or back to a SQLite file, with every row checked. See [Moving the database](https://matinee.yeix.io/docs/server/moving-the-database/).

### Fixed

- Matinee now waits for PostgreSQL for as long as it takes, showing a page that says so, instead of giving up after a few minutes.
- The Helm chart starts its bundled PostgreSQL as its own user, and adds an `appArmorProfile` setting for nodes whose kernel stops containers from signalling their own processes. See [AppArmor](https://matinee.yeix.io/docs/server/kubernetes/#apparmor).
- Arcade games no longer fail to start because of what the emulator printed.
- Server health no longer shows a title under Media analysis once it has finished.

### Apps

Version 1.0.42 of the phone and TV apps plays Steam and PC games from the game host, with a controller, from the top of a Games library. Games with no emulator on the server now say so.

### Updating

Packages, the Docker image, the Helm chart, the Mac app and the Windows app update as usual. See [Updating](https://matinee.yeix.io/docs/getting-started/updating/) in the guide.
