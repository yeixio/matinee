# Screenshot credits

The screenshots in the README show Matinee with a demo library of public-domain and Creative Commons films, cartoons, sheet music and books. Everything else in them (people, progress, file details) is made up. `pnpm shots:readme` in `site/` takes them again (see `site/demo/shoot-readme.mjs`). The artwork comes from Wikimedia Commons:
