# Stories

The example plugin in Matinee's [developer guide](https://matinee.yeix.io/docs/plugins/first-plugin/):
a library of short stories kept as `.txt` and `.md` files, with a reader
that remembers where you got to.

```sh
go test ./...
matinee-plugin try testdata/library
matinee-plugin build
```

MIT licensed, like the rest of the SDK: copy it to start your own.
